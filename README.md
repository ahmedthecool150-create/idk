# Emerald Tools (Fabric, Minecraft 26.3)

Adds emerald sword, pickaxe, axe, shovel and hoe.
Stats sit between iron and diamond. Repair with emeralds.
Recipes use emeralds + sticks, same shapes as vanilla tools.

Needs: Minecraft 26.3, Fabric Loader 0.19.3+, Fabric API 0.161.0+26.3, Java 25.

Build: push to GitHub, open the Actions tab, download the `emerald-tools-jar` artifact.
Or locally with Gradle 9.7.1 and JDK 25: `gradle build` -> `build/libs/emerald-tools-1.0.0.jar`.
